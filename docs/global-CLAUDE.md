# Canon for every project

Copy this file to `~/.claude/CLAUDE.md` so Claude Code applies it in every repo on this machine.

Default stack unless I say otherwise: Astro for sites, FastAPI for APIs, Postgres for data (SQLAlchemy async + Alembic), Redis for caching, sessions and queues, and pgvector only when a project needs embeddings or semantic search. Start new projects from the Threshold starter.

Every site and project should be immersive, dynamic and rich, drawing people in the way stepping into the deep, dark woods of a fantasy world does and holding them there in amazement.

"Deep woods" is figurative. It describes a feeling, not scenery: no trees, forests, fog or green palettes unless a project's subject calls for them. The feeling: arrival is a threshold; each project is its own world built from its subject; there is always more further in; curiosity does the navigating; the world answers the visitor.

The spell never hides the path. Navigation, the main action and prices stay visible from the first screen; body text meets WCAG AA; reduced motion gets a considered still version; sound is opt-in; pages stay fast.

One orchestrated moment per page (the arrival); after that, motion only answers the visitor.
